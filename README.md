# marketplace-laravel
Practica de creación de API 

Este mensaje fue subido luego de creado el README, o sea, luego de clonar este proyecto.

Deberás cumplir con lo que indica el caso practico brindado, el cual te ayudará a reforzar tus conocimientos al respecto de BACKEND

A continuación, estos son los comandos más comunes usados en github:

- git add . //Envuelve los cambios, los alista para ser guardados. El "." significa TODO
- git commit -m "resumenCorto" // Resume en palabras todo el cambio guardado con "add"
- git push origin nombreRama // Sube lo guardado y commiteado a la rama indicada
- git pull origin nombreRAma // Baja los últimso cambios que contenga la rama indicada
- git checkout nombreRama // Cambias de rama
- git checkout -b nombreRama // Creas y a la vez te cambias a la rama creada. "-b" indica la creación de una nueva rama
- git checkout -b nombreRama -t origin/ramaACopiar // Lo mismo de arriba, pero el "-t" y demás indica que la rama creada se basará en otra, o sea, tendrá los mismos cambios que la rama indicada luego de "-t"
- git stash // Todo lo que tengamos guardado en "git add" se almacenará localmente. Es como un "CTRL + X"
- git stash pop // Todo lo "cortado" se pega directamente en la rama donde nos encontremos
